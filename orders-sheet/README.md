# גיליון ההזמנות

כל הזמנה מהחנות נכנסת אוטומטית לגיליון Google Sheets שלך, ואת מסמנת בו מי כבר קיבל את ההזמנה.
אפשר לפתוח את הגיליון גם באקסל (קובץ → הורדה → Microsoft Excel).
על כל תשלום מגיעה גם הודעה לקבוצת טלגרם (שלב 5).

## איך זה עובד
1. קונה לוחצת "מעבר לתשלום מאובטח" → נוספת שורה עם כל הפרטים והסטטוס **ממתין לתשלום** (בצבע אפור).
2. היא משלמת ב-SUMIT וחוזרת לדף התודה → הסטטוס מתעדכן ל-**שולם**, ובקבוצת הטלגרם מופיעה הודעה כזו:
   ```
   🛒 הזמנה חדשה באתר!

   👤 דנה כהן
   הספר "באגים בהייטק" — מכירה מוקדמת × 2
   דף מדבקות "באגים בהייטק" × 1
   🚚 משלוח לחיפה
   💳 236 ש״ח

   📋 (קישור לגיליון)
   ```
   כשמשהו צריך בדיקה (למשל סכום לא תואם), מופיעה בסוף ההודעה שורה עם ⚠️.
3. כשההזמנה הגיעה אליה, את מסמנת ✓ בעמודה **קיבלו את ההזמנה**, והשורה נצבעת בירוק. בעמודה **הערות** אפשר לכתוב מה שתרצי.

העמודות: תאריך · שם · מוצרים · משלוח או איסוף · עיר · כתובת · טלפון · אימייל · סכום · סטטוס תשלום · קיבלו את ההזמנה · הערות · מספר הזמנה · מספר תשלום ב-SUMIT.

שורות בכתום כתוב בהן "לבדוק ב-SUMIT":
- **סכום לא תואם**: הסכום ששולם שונה מסכום ההזמנה.
- **מספר תשלום כפול**: אותו תשלום הופיע בשתי הזמנות.
- **חסרים פרטים**: התשלום התקבל, אבל הקונה חזרה לדף התודה מדפדפן אחר, ולכן לא ידוע לאיזו הזמנה הוא שייך. את הפרטים תמצאי ב-SUMIT לפי מספר התשלום.

שורה שנשארה **ממתין לתשלום** היא בדרך כלל קונה שפתחה את דף התשלום ולא שילמה.
אם ב-SUMIT יש חשבונית על ההזמנה הזו (למשל, הקונה סגרה את הדפדפן לפני שחזרה לאתר), שני את הסטטוס ל"שולם" בעצמך.

## הקמה (פעם אחת, בערך 10 דקות)

### 1. הגיליון והסקריפט
1. פתחי גיליון חדש ב-https://sheets.new ותני לו שם, למשל "הזמנות מהאתר".
2. בתפריט: **תוספים (Extensions) → Apps Script**.
3. מחקי את מה שכתוב שם, הדביקי את כל התוכן של הקובץ `orders-sheet/Code.gs`, ולחצי על סמל השמירה 💾.
4. בסרגל העליון, ליד כפתור **Run (הפעלה)**, בחרי את הפונקציה `setup` ולחצי **Run**.
   - Google תבקש הרשאה: **Review permissions** → בחרי את החשבון שלך → אם מופיע "Google hasn't verified this app", לחצי **Advanced** ואז **Go to ... (unsafe)** → **Allow**.
     זה הסקריפט שלך, בגיליון שלך, ורק את מריצה אותו.
5. למטה, ב-**Execution log**, תופיע השורה "הקוד הסודי ל-Cloudflare". העתיקי את הקוד (32 תווים).
   אם תצטרכי אותו שוב, הריצי את `setup` שוב: הקוד נשאר אותו קוד.

### 2. פרסום הסקריפט ככתובת
1. למעלה מימין: **Deploy → New deployment**.
2. ליד "Select type" לחצי על גלגל השיניים ⚙ ובחרי **Web app**.
3. **Execute as: Me**, **Who has access: Anyone**. לחצי **Deploy**.
4. העתיקי את ה-**Web app URL** (מתחיל ב-`https://script.google.com/macros/s/` ונגמר ב-`/exec`).
   אפשר לבדוק אותה: פתחי אותה בדפדפן, ואמור להופיע "החיבור לגיליון ההזמנות פועל."

"Anyone" לא נותן לאף אחד לראות את הגיליון. הכתובת רק מקבלת הזמנות, ורק עם הקוד הסודי.

### 3. ב-Cloudflare
1. ב-https://dash.cloudflare.com פתחי את ה-Worker ‏`ayelet-checkout`.
2. **Edit code**: מחקי הכול, הדביקי את התוכן החדש של `checkout-worker/worker.js`, ולחצי **Deploy**.
3. **Settings → Variables and Secrets → Add**:
   - `ORDERS_SHEET_URL`: הכתובת משלב 2 (Type: Text)
   - `ORDERS_SHEET_TOKEN`: הקוד הסודי משלב 1 (Type: **Secret**)

   ולחצי **Deploy**.

### 4. בדיקה
פתחי את https://ayeletsapirshtein.com/?test ושלמי 1 ש״ח על פריט הבדיקה.
מיד כשנפתח דף התשלום אמורה להופיע בגיליון שורה "ממתין לתשלום", ואחרי התשלום היא אמורה להתעדכן ל"שולם".
את שורת הבדיקה אפשר למחוק.

אם לא מופיעה שורה: ב-Cloudflare, ב-Worker, בלשונית **Logs**, יופיעו שגיאות שמתחילות ב-"orders sheet". שלחי לי אותן.

### 5. הודעות בטלגרם
**יצירת הבוט** (הבוט הוא מי ששולח את ההודעות לקבוצה):
1. בטלגרם, פתחי צ'אט עם **@BotFather** (יש לו וי כחול) ושלחי `/newbot`.
2. הוא ישאל שם (למשל `הזמנות מהאתר`), ואז שם משתמש באנגלית שנגמר ב-`bot` (למשל `ayelet_orders_bot`).
3. בתשובה הוא ישלח **טוקן**, שורה שנראית כמו `1234567890:AAH...`. העתיקי אותה.
   אל תשלחי אותה לאף אחד: מי שיש לו את הטוקן יכול לשלוח הודעות בשם הבוט.

**הקבוצה:**
1. צרי קבוצה חדשה בטלגרם (או השתמשי בקיימת) והוסיפי אליה את הבוט כחברה, לפי שם המשתמש שלו.
2. כתבי בקבוצה `/start`.

**חיבור לגיליון:**
1. ב-Apps Script, בתפריט שמשמאל, לחצי על גלגל השיניים ⚙ (**Project Settings**).
2. גללי למטה ל-**Script Properties** → **Add script property**:
   - Property: `TELEGRAM_TOKEN`
   - Value: הטוקן מ-BotFather

   ולחצי **Save script properties**. את המאפיין `TOKEN` שכבר מופיע שם אל תשני: זה הקוד הסודי של Cloudflare.
3. חזרי לעורך (הסמל `<>` בתפריט שמשמאל), בחרי את הפונקציה `connectTelegram` ולחצי **Run**.
   Google תבקש הרשאה חדשה, "Connect to an external service", כי הסקריפט פונה עכשיו לטלגרם. אשרי כמו בשלב 1.
4. בקבוצה תופיע ההודעה "✅ מחובר!".
5. **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**. בלי השלב הזה האתר ממשיך להשתמש בגרסה בלי טלגרם.

בדיקה: הזמנת בדיקה של 1 ש״ח דרך `/?test`. אחרי התשלום אמורה להגיע הודעה לקבוצה.

אם `connectTelegram` כותבת "לא מצאתי קבוצה": כתבי שוב `/start` בקבוצה והריצי אותה שוב.

**אם `connectTelegram` כותבת שטלגרם לא עונה (Too Many Requests):** מזינים את מספר הקבוצה ידנית.
1. בדפדפן, פתחי את הכתובת הזו, ובמקום `הטוקן` הדביקי את הטוקן המלא מ-BotFather (בלי רווחים):
   `https://api.telegram.org/botהטוקן/getUpdates`
2. בדף שנפתח חפשי (Cmd+F) את שם הקבוצה. לפני השם מופיע משהו כמו `"chat":{"id":-1001234567890,"title":"שם הקבוצה"`.
   העתיקי את המספר, **כולל המינוס** שלפניו. אם הדף כמעט ריק, כתבי `/start` בקבוצה ורענני.
3. ב-Apps Script: ⚙ **Project Settings → Script Properties → Add script property**:
   Property `TELEGRAM_CHAT_ID`, Value המספר. שמרי.
4. הריצי שוב את `connectTelegram`. עכשיו היא רק שולחת "✅ מחובר!" לקבוצה.
   כדי לעבור בעתיד לקבוצה אחרת, מוחקים את `TELEGRAM_CHAT_ID` ומריצים שוב.
טלגרם שומרת את ההודעות האלה לבוט רק 24 שעות, אז כדאי להריץ את הפונקציה סמוך להוספת הבוט לקבוצה.

## שינוי הסקריפט בעתיד
אחרי שמדביקים קוד חדש ב-Apps Script, צריך **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**.
כך הכתובת נשארת אותה כתובת, ולא צריך לשנות כלום ב-Cloudflare.

## חשוב לדעת
- הגיליון לא נוגע בעמודות "קיבלו את ההזמנה" ו"הערות" אחרי שהשורה נוצרה, אז מה שאת כותבת שם נשמר.
- אפשר למיין ולסנן (יש מסנן בשורת הכותרת), למחוק שורות, ולהוסיף עמודות משלך אחרי העמודה האחרונה (משמאל לה).
  לא כדאי להזיז, להוסיף באמצע או למחוק את העמודות הקיימות: הסקריפט מוצא אותן לפי המיקום שלהן.
- אם הגיליון לא זמין לרגע, התשלום עדיין עובד כרגיל. החשבונית ב-SUMIT היא תמיד המקור הקובע.
- אם טלגרם לא זמינה, ההזמנה עדיין נשמרת בגיליון. רק ההודעה לא תגיע.
- ההודעה בטלגרם נשלחת כשהקונה חוזרת לדף התודה. קונה שסגרה את הדפדפן לפני כן לא תקבל הודעה, כמו בגיליון.
- כל מי שבקבוצה רואה את שם הקונה, המוצרים והעיר. טלפון, אימייל וכתובת מופיעים רק בגיליון.
