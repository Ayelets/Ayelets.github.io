# פורטפוליו — איילת

זהו סטארטר לאתר סטטי (HTML/CSS/JS) ב-RTL, מותאם ל-GitHub Pages.

## איך משתמשים
1. החליפי את הקבצים בתיקיית `images` בצילומים שלך בשמות דומים (`work-1.jpg` וכו').
2. ערכי את הקובץ `index.html` (כותרות/טקסט/קישורים).
3. פרסי ל-GitHub Pages:
   - צרי ריפו `ayelets.github.io` או ריפו פרויקט (ואז ה-URL יהיה `/שם-הריפו`).
   - העלי את כל הקבצים לשורש הריפו.
   - Settings → Pages → Source: `main` / `root`.
4. אפשר לקשר דומיין מותאם **Namecheap**:
   - CNAME: `www` → `ayelets.github.io`
   - A records ל-`@`:
     185.199.108.153
     185.199.109.153
     185.199.110.153
     185.199.111.153
