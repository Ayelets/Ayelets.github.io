# פורטפוליו — איילת ספירשטיין

אתר סטטי (HTML/CSS/JS) בעברית, מימין לשמאל, שמתפרסם דרך GitHub Pages בכתובת
[ayeletsapirshtein.com](https://ayeletsapirshtein.com).

## מבנה
- `index.html` — כל תוכן האתר (פתיח, גלריה, אודות, יצירת קשר).
- `styles.css` — העיצוב. הצבעים והגופנים מוגדרים כמשתנים בראש הקובץ.
- `script.js` — לייטבוקס עם מעבר בין עבודות (חיצים, מקלדת והחלקה), ואנימציות גלילה.
- `images/` — קובצי המקור של העבודות (PNG).
- `images/web/` — גרסאות WebP מוקטנות שהאתר משתמש בהן בפועל.
- `assets/` — פאביקון ותמונת שיתוף לרשתות חברתיות (`og.jpg`).

## SEO ו-GEO (מנועי חיפוש ועוזרי AI)
- `robots.txt` — מאפשר לכל מנועי החיפוש ולסורקים של עוזרי AI (ChatGPT, Claude, Perplexity, Gemini) לקרוא את האתר, ומפנה ל-sitemap.
- `sitemap.xml` — רשימת העמודים והתמונות. כשמוסיפים עמוד חדש, מוסיפים אותו גם כאן.
- `llms.txt` — תקציר של האתר ושל הספר בשביל עוזרי AI. כשמשתנים מחיר, מוצר או עמוד, מעדכנים גם כאן.
- בראש כל עמוד יש בלוק `application/ld+json` (נתונים מובנים: הספר, המוצרים והמחירים, העבודות). מחיר שמשתנה בעמוד צריך להשתנות גם שם.
- `404.html` — העמוד שמוצג לכתובת שלא קיימת.

## החנות
- `shop/` — העגלה ודף התודה.
- `checkout-worker/` — השרת הקטן ב-Cloudflare שפותח את דף התשלום ב-SUMIT. ההוראות ב-`checkout-worker/README.md`.
- `orders-sheet/` — הסקריפט ששומר כל הזמנה בגיליון Google Sheets, עם עמודה לסמן מי קיבל את ההזמנה, ושולח הודעה לקבוצת טלגרם על כל תשלום. ההוראות ב-`orders-sheet/README.md`.

## מדידה (Google Analytics ו-Meta Pixel)
- **החנות** (`shop/shop.js`, `shop/thanks/index.html`): צפייה במוצר, הוספה לעגלה, תחילת תשלום, בחירת משלוח, ורכישה בדף התודה (פעם אחת לכל הזמנה). מוצר הבדיקה לא נספר.
- **ווטסאפ**: לחיצה על הכפתור נספרת כ-`contact_whatsapp` ב-GA וכ-Contact ב-Meta.
- **פורטפוליו** (`script.js`): `view_artwork` עם שם העבודה שנפתחה בתצוגה הגדולה.
- **הפרק הראשון**: `chapter_page` עם מספר העמוד (פעם אחת לכל עמוד בביקור), `chapter_finished`, ו-`generate_lead` בלחיצה על ״אני רוצה לקנות״.

## הוספת עבודה חדשה
1. שימי את קובץ ה-PNG בתיקיית `images` (שם הקובץ הוא גם הכותרת).
2. הוסיפי שורה לרשימה `WORKS` בקובץ `tools/optimize_images.py` — שם הקובץ ושם קצר באנגלית.
3. הריצי מתיקיית השורש:
   ```
   python3 tools/optimize_images.py
   ```
   הסקריפט יוצר את קובצי ה-WebP ומדפיס את קוד ה-HTML של כל העבודות — העתיקי את הבלוק לתוך `<div class="gallery">` ב-`index.html`.

## פרסום
כל דחיפה לענף `main` מתפרסמת אוטומטית ב-GitHub Pages (Settings → Pages → Source: `main` / root).
הדומיין המותאם מוגדר בקובץ `CNAME`.
