# חיבור התשלום ל-SUMIT

האתר עצמו לא יכול לפנות ל-SUMIT, כי מפתח ה-API חייב להישאר סודי.
לכן יש "שרת קטן" (Cloudflare Worker, חינמי) שמחזיק את המפתח:
הקונה ממלאת עגלה ופרטים → השרת הקטן מבקש מ-SUMIT דף תשלום עם הסכום → הקונה משלמת ב-SUMIT (סליקה דרך Upay) → חוזרת לדף התודה באתר.

המחירים נלקחים מהקובץ `worker.js` בלבד, כך שאי אפשר לשנות אותם מהדפדפן.

## הקמה (פעם אחת, בערך 15 דקות)

### 1. ב-SUMIT: מספר חברה ומפתח API
1. ודאי שמודול ה-API מותקן בחשבון.
2. בדף המפתחים של SUMIT (app.sumit.co.il/developers/api) העתיקי את **מספר החברה (Company ID)** וצרי **מפתח API פרטי (API Key)**.
   אל תשלחי את המפתח במייל או בצ'אט — הוא נכנס רק ל-Cloudflare בשלב 2.

### 2. ב-Cloudflare: יצירת ה-Worker
1. פתחי חשבון חינמי ב-https://dash.cloudflare.com.
2. **Workers & Pages → Create → Create Worker**. שם: `ayelet-checkout`. לחצי **Deploy**.
3. **Edit code**: מחקי את כל מה שיש, הדביקי את כל התוכן של `checkout-worker/worker.js`, ולחצי **Deploy**.
4. **Settings → Variables and Secrets → Add**:
   - `SUMIT_COMPANY_ID` — מספר החברה (Type: Text)
   - `SUMIT_API_KEY` — מפתח ה-API (Type: **Secret**)
   ולחצי **Deploy**.
5. העתיקי את כתובת ה-Worker (נראית כמו `https://ayelet-checkout.<שם>.workers.dev`).

### 3. באתר: חיבור הכפתור
בקובץ `shop/config.js` הדביקי את כתובת ה-Worker בין המירכאות, ופרסמי (או שלחי לי את הכתובת ואעשה את זה).
מרגע זה כפתור "לתשלום" בעגלה פעיל.

### 4. בדיקה
בצעי הזמנה אחת קטנה בעצמך (למשל כרטיס ברכה) ובדקי ש:
- נפתח דף התשלום של SUMIT עם הסכום הנכון,
- אחרי התשלום חוזרים לדף התודה והוא מציג "התשלום התקבל",
- החשבונית נוצרה ב-SUMIT ונשלחה במייל.

## שינוי מחירים או מוצרים
המחירים מופיעים בשני מקומות, וצריך לעדכן את שניהם:
- `shop/shop.js` ו-`shop/index.html` — מה שמוצג באתר.
- `checkout-worker/worker.js` — מה שבאמת נגבה. אחרי שינוי, הדביקי את הקובץ מחדש ב-Cloudflare (שלב 2.3).

דמי משלוח: `SHIPPING_PRICE` בראש `worker.js` ובראש `shop/shop.js` (כרגע 35 ש״ח; איסוף עצמי חינם).
